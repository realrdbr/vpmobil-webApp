<h1>Modern VPMobil-WebApp build with Python</h1>
<br>
<br>
<p>This is a new and modern UI for VPMobil Substitution Software. It uses the repaired python libary vpmobil-py.</p>
<br>
<h2>Features:</h2>
<p><ul>
  <li>Substitution plan from the VPMobil-Server</li>
  <li>Free room lookup</li>
  <li>Teacher plan</li>
</ul></p>
<br>
<h3>Benefits:</h3>
<p>No new backend required since it uses the existing Servers</p>
<p>Modern UI</p>
<p>Fetches all classes automatically</p>
<p>only needs set-up once with school-login-data</p>
<br>
<br>
<h2>Setup Guide:</h2>
<p><ol>
<li>Pull the repository</li>
<li>Install the dependencies with pip install -r requirements.txt</li>
<li>Rename the .env.example to .env</li>
<li>Enter the VPMobil informations and other informations to the new .env</li>
<li>Run the main.py</li>
<li>Access the website with 127.0.0.1:8000 or the changed address from the .env</li>
</ol></p>
